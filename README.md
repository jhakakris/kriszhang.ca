# kriszhang.ca

Personal website of Junhao (Kris) Zhang: projects, research, publications and CV.

It is a static site with no build step: `index.html`, `style.css`, images in `assets/` and documents (papers, reports, slides, CV) in `files/`.

To preview locally:

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000.
